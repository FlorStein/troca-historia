# Troca — La historia

Experiencia web móvil que presenta el origen, el modelo de intercambio, la seguridad y la proyección regional de Troca.

## Uso local

Abrí `index.html` en un navegador. Es una web estática, sin dependencias ni proceso de compilación.

## Contenido

- Narrativa de origen y propuesta de valor.
- Modelo 1:1 de puntos para estadías cumplidas.
- Reglas de confianza y seguridad.
- Cambio de idioma entre español y portugués.
- Diseño mobile-first con efecto parallax al desplazarse.
